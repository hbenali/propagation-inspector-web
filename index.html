What this can and cannot tell you

Your browser sends each question to the resolver's DNS-over-HTTPS endpoint, so it can only use resolvers that allow requests from web pages. Each of them is an anycast service with caches shared across many locations. You do not choose which node answers, and you cannot query a domain's authoritative servers from here. Treat the table as a coarse view, not a global one. A change that shows everywhere here can still be stale elsewhere, and a difference can also be geo-DNS or round-robin rather than propagation.
